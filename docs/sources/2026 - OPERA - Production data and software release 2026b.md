## What it is

The list of changes of OPERA release 2026b: new radars, renamed files, and software versions (CIRRUS 1.7.0 with no software update).

## Numbers we use

- **Belgian radars EBUM41, EBUM42 and EBUM43** (page 2): reflectivity volume files renamed. Belgium previously delivered four reflectivity products (TH, wind-optimised DBZH, best DBZH and Doppler-filtered DBZH); after the filename change the Doppler-filtered DBZH is no longer delivered. NIMBUS needed reconfiguration; the QC volumes change because of it.
- **CIRRUS 1.7.0** (page 3): "No software updates".

## Relevance to DECADE

#88: Belgian radars deliver more than one DBZH product, so which of them CIRRUS uses matters for the level over Belgium. This release is dated 2/11/2026, after the period of the 2026 drop (1–8/2026), so it does not explain it; CIRRUS after 2/11/2026 may change again over Belgium.

## Limits

- The notes do not say which Belgian DBZH product CIRRUS composites, nor which station each EBUM code is.
